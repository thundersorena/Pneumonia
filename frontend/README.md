# رابط تحلیل PneumoniaCNN

رابط Next.js فارسی و راست‌چین برای بارگذاری تعاملی تصویر رادیوگرافی و نمایش پیش‌بینی مدل. اجزای `Button` و `Card` در `components/ui` با الگوی componentهای shadcn/ui پیاده‌سازی شده‌اند؛ برای راه‌اندازی این رابط به کتابخانه‌ی کامپوننت جداگانه‌ای نیاز نیست.

## اجرای پروژه

از پوشه‌ی اصلی پروژه، ابتدا API پایتون را در یک ترمینال راه‌اندازی کنید:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r backend\requirements.txt
python -m uvicorn backend.main:app --reload
```

فایل `pneumonia_cnn.pt` باید در ریشه‌ی پروژه باشد. API به‌صورت پیش‌فرض روی `http://127.0.0.1:8000` اجرا می‌شود. پس از دیدن پیام `Application startup complete`، در ترمینال دیگری می‌توانید آماده بودن مدل را بررسی کنید:

```powershell
Invoke-RestMethod http://127.0.0.1:8000/health
```

پاسخ مورد انتظار `{"status":"ready"}` است. اگر خطای نبودن `torch` یا `torchvision` دیدید، مطمئن شوید محیط مجازی فعال است و نصب وابستگی‌ها کامل شده است.

در ترمینال دوم، فرانت‌اند را اجرا کنید:

```powershell
cd frontend
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید. وضعیت API در نوار بالای صفحه نمایش داده می‌شود. برای آدرس API متفاوت، متغیر `NEXT_PUBLIC_API_URL` را هنگام اجرای Next.js تنظیم کنید.

## ورودی و محدودیت‌ها

- فایل JPG یا PNG تا ۱۰ مگابایت پذیرفته می‌شود.
- API تصویر را grayscale و به اندازه‌ی `28 × 28` تبدیل می‌کند و از آستانه‌ی `0.3` ذخیره‌شده در checkpoint استفاده می‌کند.
- معماری CNN از ابعاد وزن‌ها و نام لایه‌های checkpoint بازسازی شده است. چون checkpoint به‌تنهایی جزئیات کامل کد آموزش و پیش‌پردازش را ذخیره نمی‌کند، خروجی باید با pipeline آموزش مدل تطبیق و ارزیابی شود.
- این ابزار پژوهشی است و برای تشخیص پزشکی یا تصمیم‌گیری درمانی طراحی نشده است.
